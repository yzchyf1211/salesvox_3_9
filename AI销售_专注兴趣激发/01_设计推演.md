# AI销售（专注兴趣激发）— 设计推演

## 第一部分：架构总览

### 角色

```
名字:  Vox
定位:  1v1 演绎型 AI 销售，专注兴趣激发
场景:  在线对话，与潜在客户实时交流
```

### AOM 层级

```
__root__（Session，永不结束）
 │
 └── sales_project（销售项目）
      │  产品信息、客户画像、销售策略
      │
      └── encounter（一次客户触达）
           │  客户档案、对话历史、意向状态
           │
           ├── phase:rapport      建立关系
           ├── phase:discovery    需求挖掘
           ├── phase:spark        兴趣激发
           └── phase:advance      推进行动
```

### 四个 Task 一句话定义

| Task | name | 一句话 | 结束条件 |
|------|------|--------|---------|
| 建立关系 | `phase:rapport` | 破冰寒暄，找到共同话题，建立信任感 | 客户放下防备，愿意聊 |
| 需求挖掘 | `phase:discovery` | 提问探测现状、挑战和期望 | 摸清至少一个核心痛点 |
| 兴趣激发 | `phase:spark` | 用场景/案例/数据点燃兴趣 | 客户主动追问或表达认可 |
| 推进行动 | `phase:advance` | 确认意向，克服犹豫，约定下一步 | 客户同意具体行动（试用/见面/下单） |

### Skill 分配

| Skill | 说明 | 谁用 |
|-------|------|------|
| `manage_task` | 任务编排与生命周期管理 | 所有层通用（框架默认） |
| `consultative_selling` | 顾问式销售全流程方法论 | encounter 层通用 |
| `spin_questioning` | SPIN 提问法（现状→问题→影响→需求） | discovery |
| `scenario_storytelling` | 场景化故事讲述方法论 | spark |
| `objection_reframing` | 异议转化方法论 | advance |

### Tool 分配

| Tool | 说明 | 谁用 |
|------|------|------|
| `_builtin_conversation` | 与客户对话（ask_question=true 等回复） | 所有 Task 通用 |
| `_builtin_send_user_content` | 展示内容卡片给客户 | spark, advance |
| `_builtin_write_scratchpad` | Agent 记录客户洞察/思路（客户看不到） | discovery, spark |
| `show_product_material` | 展示产品资料/案例/数据 | spark 专属 |

### Card 分配

| Card | 触发 action | 所属 Task | 展示什么 |
|------|-------------|----------|---------|
| `case-study-card` | `"show_case"` | spark | 客户成功案例（公司名+痛点+效果+数据） |
| `product-highlight-card` | `"show_highlight"` | spark | 产品亮点（核心功能+差异化价值） |
| `next-step-card` | `"show_next_step"` | advance | 下一步行动选项（试用/演示/见面） |

### 一张图

```
System Prompt
│  "你是 Vox，一个顾问式销售专家..."
│
├─ Skill: manage_task ──────────────────── 所有层
├─ Skill: consultative_selling ─────────── encounter 层
│
├─ sales_project 层
│   State: + product_info, target_persona, sales_strategy
│   abefore: 加载产品信息、客户画像、销售话术策略
│
└─ encounter 层
    State: + customer, interaction_history, intent_level
    abefore: 加载客户档案、历史互动、当前意向
    Tools: _builtin_conversation
    │
    ├── phase:rapport ─── 建立关系
    │   Tools: _builtin_conversation
    │   进入: 注入客户背景 + 破冰话题建议
    │   退出: 记录客户态度
    │
    ├── phase:discovery ─── 需求挖掘
    │   Skill: spin_questioning
    │   Tools: _builtin_conversation, _builtin_write_scratchpad
    │   进入: 注入 SPIN 提问框架 + 行业痛点参考
    │   退出: 汇总已挖掘痛点 → state.discovered_pains
    │
    ├── phase:spark ─── 兴趣激发（核心）
    │   Skill: scenario_storytelling
    │   Tools: _builtin_conversation, _builtin_send_user_content,
    │          _builtin_write_scratchpad, show_product_material
    │   Cards: case-study-card, product-highlight-card
    │   进入: 注入匹配痛点的案例/场景 + 产品亮点
    │   退出: 记录客户兴趣信号 → state.interest_signals
    │
    └── phase:advance ─── 推进行动
        Skill: objection_reframing
        Tools: _builtin_conversation, _builtin_send_user_content
        Cards: next-step-card
        进入: 注入已确认兴趣点 + 可推进的行动选项
        退出: 记录约定的下一步 → state.next_action

---

以上为架构全貌。第二部分（各环节设计细节与方法论）待续。
```
