## 1. 总览

设计一个演绎角色需要交付以下设计物，每个设计物对应后端的一个代码结构：

| 序号 | 设计物 | 后端对应 | 数量 |
|------|--------|---------|------|
| 1 | AOM 层级定义 | 每层一个 `TaskMiddleware` 子类 | 每层 1 个 |
| 2 | State Schema | 每层一个 `TypedDict` 子类 | 每层 1 个 |
| 3 | Task Handler | 每种叶子任务一个 `TaskHandler` 子类 | 每种任务类型 1 个 |
| 4 | System Prompt | `__main__.py` 中的 `SYSTEM_PROMPT` 字符串 | 全局 1 份 |
| 5 | Task Prompt | Langfuse 中按 handler.name 加载的 TASK.md | 每种任务类型 1 份 |
| 6 | Context 模板 | Langfuse 中的 prompt 模板（带 `{{变量}}`） | 每层若干个 |
| 7 | Tool | `@tool` 装饰的 async 函数 | 按需 |
| 8 | Card | `AOMCard` TypedDict 实例 | 每种展示形态 1 个 |

## 2. AOM 层级定义

### 后端对应

每个 AOM 层级对应一个继承自 `TaskMiddleware`（或 `EnhanceTaskMiddleware`）的类。

```python
# 后端类定义位置: agentickit/prosonaagent/core/middleware/task_middleware.py
# AOM 层定义位置: agentickit/prosonaagent/aom/middlewares/
```

### 设计格式

每一层填写以下表格：

```
层级名（task_group_name）:  ___
  说明:                      一句话描述这一层管理什么
  父类:                      TaskMiddleware | EnhanceTaskMiddleware
                             （需要 Card 展示能力的层用 EnhanceTaskMiddleware）
  子层（sub_task_group_name）: ___（叶子层填 null）
  是否叶子（allow_sub_tasks）: true | false
  状态类（state_schema）:      ___TaskState（对应 §3 中定义的 State）

  生命周期:
    abefore（进入时）:
      加载数据:   调什么 API / 查什么数据 → 写入 state 的哪个字段
      注入上下文:  构造什么 SystemMessage → 追加到 messages
      发送通知:   发什么 A2A lifecycle 消息 / 调什么外部 API
    apause（暂停时）:  ___
    aresume（恢复时）:  ___
    ainterrupt（中断时）: ___
    arecover（恢复中断时）: ___
    aafter（正常结束时）: ___

  内置工具（tools）:
    - 列出本层 Middleware 类级别绑定的 tool（如 _builtin_conversation）

  技能列表（skills）:
    - 列出本层需要的 skill 名称
```

### 字段说明（与代码严格对齐）

| 字段 | 代码属性 | 类型 | 说明 |
|------|---------|------|------|
| 层级名 | `task_group_name: str` | string | 中间件的分组标识，如 `"project"` / `"activity"` / `"sco"` |
| 子层 | `sub_task_group_name: Optional[str]` | string \| null | 子层的 task_group_name，叶子层为 null |
| 是否叶子 | `allow_sub_tasks: bool` | boolean | `false` 时不暴露 `_builtin_start_task` / `_builtin_recover_task` |
| 状态类 | `state_schema: type` | TypedDict class | 本层使用的 State 类型 |
| 内置工具 | `tools: List[Any]` | list | 类级别声明的工具列表 |
| 技能列表 | `skills: List[str]` | list[string] | 需要注入上下文的技能名 |

### 生命周期方法签名（所有层统一）

```python
async def abefore(self, state: XxxTaskState, runtime: Runtime) -> Dict[str, Any]
async def apause(self, state: XxxTaskState, runtime: Runtime) -> Dict[str, Any]
async def aresume(self, state: XxxTaskState, runtime: Runtime) -> Dict[str, Any]
async def ainterrupt(self, state: XxxTaskState, runtime: Runtime) -> Dict[str, Any]
async def arecover(self, state: XxxTaskState, runtime: Runtime) -> Dict[str, Any]
async def aafter(self, state: XxxTaskState, runtime: Runtime) -> Dict[str, Any]
```

返回值是**增量 Dict**，框架自动 merge 到 state。其中 `messages` 字段会追加（不覆盖）。

### Root 层特殊规则

- Root 层的 `task_group_name` 固定为 `"__root__"`
- Root 层**永不结束**（不实现 `aafter`，调用会抛异常）
- Root 层的 `abefore` 需要注入一个 `_builtin_start_task` 的 AIMessage 来自动启动第一个子任务

## 3. State Schema（状态字段）

### 后端对应

每层 State 是一个 TypedDict，层层继承。子层能看到所有父层的字段。

```python
# 框架基础: agentickit/prosonaagent/core/middleware/task_state.py
# AOM 扩展: agentickit/prosonaagent/aom/state.py
# 业务扩展: 各 handler 文件内
```

### 框架内置字段（不需要设计，自动存在）

以下字段由框架的 `AgentState` → `ProsonaAgentState` → `TaskState` 提供，所有层自动继承：

```
# AgentState（langchain 内置）
messages:        list[AnyMessage]       # 消息列表

# ProsonaAgentState
context_id:      str                    # 会话ID
parts:           list[Part]             # A2A 请求体 part 信息
text_part_size:  int                    # 文本类型消息数量
user_profile:    Optional[UserProfile]  # 用户信息
locale:          Optional[str]          # 语言代码（zh_CN / en / ja）
locale_name:     Optional[str]          # 语言描述

# TaskState
id:              Optional[str]          # 当前任务ID
name:            Optional[str]          # 当前任务名
status:          Optional[str]          # pending | running | paused | completed | interrupted | recovering
params:          Optional[dict]         # 启动参数（start_task 传入的）
sub_tasks:       List[str]              # 子任务ID列表
result:          Optional[Dict[str,Any]]# 结束结果
mode:            Optional[str]          # "start" | "recover"
```

### 设计格式

每一层只设计**本层新增的字段**：

```
State 名称:  ___TaskState
继承自:      ___TaskState（上一层的 State）
新增字段:
  - 字段名: 类型           # 说明
  - 字段名: 类型           # 说明
```

### 类型约定

| 写法 | Python 类型 | 说明 |
|------|------------|------|
| `str` | `str` | 字符串 |
| `int` | `int` | 整数 |
| `float` | `float` | 浮点数 |
| `bool` | `bool` | 布尔 |
| `dict` | `Dict[str, Any]` | 任意字典 |
| `list[str]` | `List[str]` | 字符串列表 |
| `list[XxxSchema]` | `List[XxxSchema]` | 特定类型列表 |
| `Optional[str]` | `Optional[str]` | 可为 None 的字符串 |

### 业务实体类型（TypedDict）设计格式

当 State 中引用的类型不是基础类型时，需要同时设计该实体的结构：

```
类型名称:  XxxSchema
字段:
  - 字段名: 类型           # 说明
  - 字段名: 类型           # 说明
```

对应后端代码：

```python
class XxxSchema(TypedDict):
    字段名: 类型
```

## 4. Task Handler（任务处理器）

### 后端对应

每种叶子任务类型对应一个 `TaskHandler`（或 `EnhanceTaskHandler`）子类。

```python
# 基类: agentickit/prosonaagent/core/handler/task_handler.py
# 增强基类（支持 Card）: agentickit/prosonaagent/core/handler/enhance_task_handler.py
# 业务实现: app/handlers/
```

### 设计格式

```
Handler 名称:              ___（Python 类名，如 QuizTaskHandler）
注册名（name）:            ___（格式: "叶子层group_name:任务类型"，如 "sco:quiz"）
父类:                      TaskHandler | EnhanceTaskHandler
                           （需要 Card 展示能力用 EnhanceTaskHandler）
状态类（state_schema）:     ___TaskState（在 SCOTaskState 等基础上扩展）
模型组（model_group）:      ___（默认 "main"，可选。对应 config 中 model_groups.xxx）

扩展状态字段:
  - 字段名: 类型           # 说明（这些字段会合并到 state_schema）

工具列表（tools）:
  - tool_name              # 每个 tool 的详细定义见 §8

技能列表（skills）:
  - skill_name             # 会与 Middleware 层的 skills 合并去重

生命周期:
  abefore（进入时）:
    加载:    ___
    注入:    ___（哪些 Context 模板 → SystemMessage）
    额外:    ___
  aafter（正常结束时）:    ___
  ainterrupt（中断时）:    ___
  aresume（恢复时）:       ___
  apause（暂停时）:        ___
  arecover（恢复中断时）:  ___

子任务生命周期（如果当前 handler 所在层有子任务）:
  abefore_task(state, runtime, sub_task_id, sub_task_name):  ___
  aafter_task(state, runtime, sub_state):                     ___
  ainterrupt_task(state, runtime, sub_state):                 ___

用户输入处理:
  aafter_user_input(state, runtime, user_input, action, params): ___

Card 渲染（仅 EnhanceTaskHandler）:
  aget_card(state, action, params) -> AOMCard:
    支持的 action 列表:
      - action_name_1:  触发时机 / 卡片内容描述
      - action_name_2:  触发时机 / 卡片内容描述
```

### Handler 查找规则（框架自动处理）

当 LLM 启动一个任务时，框架按以下顺序查找 Handler：

1. `"{task_group_name}:{task_name}"` — 精确匹配（如 `"sco:quiz"`）
2. `"{task_group_name}"` — 组默认（如 `"sco"`）
3. `"general"` — 全局兜底

### name 命名规则

```
格式:  {所在AOM层的task_group_name}:{任务类型标识}
示例:  sco:quiz
       sco:lecture_summary
       sco:multimodal_content
       activity:custom_activity_type
```

## 5. System Prompt（全局人设）

### 后端对应

```python
# __main__.py 中的 SYSTEM_PROMPT 字符串
# 传入 create_prosona_agent(system_prompt=SYSTEM_PROMPT, ...)
# 全局共享，所有层级所有任务都能看到
```

### 设计格式

```markdown
# Role
（你是什么角色——一句话定义职能）

# Persona
（你叫什么名字，性格特点，说话风格）

# Task
（你的核心任务是什么——宏观描述，不涉及具体任务类型）
- **编排任务:** ___
- **执行任务:** ___

# Constraints
（场景限制、行为约束、输出格式要求）

## 场景限制
- ___
- ___

## 输出格式
- ___
- ___
```

### 注意事项

- System Prompt **全局唯一**，不要把具体任务类型的指令写在这里
- 具体任务的行为指令写在 Task Prompt（§6）中
- 保持简洁，这是 LLM 每次调用都会看到的内容

## 6. Task Prompt（任务行为指令）

### 后端对应

```python
# 通过 Langfuse 管理，按 handler.name 加载
# 代码调用: get_task_prompt(name=handler.name)
# 在 TaskMiddleware.abefore() 中自动加载并注入为 SystemMessage
```

### 设计格式

每种 Task 类型（即每个 Handler）一份：

```
Prompt 名称:  与 handler.name 一致（如 "sco:quiz"）
存储位置:     Langfuse prompt，key 由框架自动映射

--- Prompt 内容 ---

# Task: {任务类型的可读名称}

## 目标
（这个任务要达成什么）

## 步骤
1. ___
2. ___
3. ___

## 结束条件
（什么情况下调用 end_task）

## 注意事项
- ___
- ___

## 可用动作（action）
（如果该任务有 Card 展示，列出 _builtin_send_user_content 的 action 值）
- action_name_1: 说明
- action_name_2: 说明
```

### 与 System Prompt 的关系

```
System Prompt:  "你是 XXX，你的整体职责是..."     ← 全局，不变
Task Prompt:    "你现在正在做 XXX 任务，步骤是..." ← 每个任务不同，任务启动时注入
Context:        "当前的具体数据是..."              ← 每次运行不同，实时注入
```

## 8. Tool（工具 / 技能）

### 后端对应

```python
# 使用 @tool 装饰器定义
# 来自 langchain_core.tools.tool
# 注册方式: 写在 Handler.tools 列表 或 Middleware.tools 列表中
```

### 框架内置 Tool（不需要设计，自动可用）

以下工具由框架提供，所有层级自动可用：

| 工具名 | 参数 | 说明 | 来源 |
|--------|------|------|------|
| `_builtin_start_task` | `name: str`, `params: Optional[dict]` | 启动子任务 | TaskMiddleware（allow_sub_tasks=true 时） |
| `_builtin_end_task` | `is_interrupt: bool`, `result: Optional[dict]` | 结束当前任务 | TaskMiddleware（所有层） |
| `_builtin_recover_task` | `task_id: str`, `task_name: str` | 恢复被中断的任务 | TaskMiddleware（allow_sub_tasks=true 时） |
| `_builtin_get_skill_information` | `name: str` | 获取技能详情 | TaskMiddleware（所有层） |
| `_builtin_get_skill_resource` | `name: str`, `path: str` | 获取技能资源文件 | TaskMiddleware（所有层） |
| `_builtin_send_user_content` | `action: str`, `params: Optional[dict]` | 发送内容给用户展示（触发 Card） | EnhanceTaskMiddleware |
| `_builtin_conversation` | `text: str`, `ask_question: bool` | 与用户对话 | 需在 Middleware.tools 或 Handler.tools 中声明 |
| `_builtin_write_scratchpad` | `text: str` | 写草稿本（帮助 Agent 记录思路） | 需在 tools 中声明 |

### 自定义 Tool 设计格式

```
工具名称（函数名）:  ___
描述（docstring）:   ___（给 LLM 看的，LLM 据此决定何时调用）
注册位置:            Handler.tools / Middleware.tools

参数:
  - 参数名: 类型     # 说明（写在 Args docstring 中）
  - 参数名: 类型     # 说明

返回行为:
  - 返回什么 ToolMessage 内容
  - 是否修改 state（通过 Command(update={...})）
  - 是否触发 interrupt（暂停等待用户输入）

副作用:
  - 调用什么外部 API
  - 写入什么存储
```

### 代码模板（研发参考）

```python
@tool
async def tool_name(
    arg1: str,
    arg2: Optional[int] = None,
    tool_runtime: ToolRuntime = None,
) -> Command:
    """
    工具描述（这段文字会被 LLM 看到）

    Args:
        arg1: 参数1说明
        arg2: 参数2说明
    """
    tool_call_id = tool_runtime.tool_call_id
    state = tool_runtime.state

    # ... 业务逻辑 ...

    return Command(update={
        "messages": [ToolMessage(
            content=build_tool_call_success_system_feedback("结果文本"),
            tool_call_id=tool_call_id,
        )],
        # 可选: 更新 state 字段
        # "field_name": new_value,
    })
```

### Tool 的三种行为模式

| 模式 | 说明 | 代码特征 |
|------|------|---------|
| 纯返回 | 执行逻辑，返回结果给 LLM | 只返回 `Command(update={"messages": [ToolMessage(...)]})` |
| 修改状态 | 执行逻辑 + 修改 state 字段 | `Command(update={"messages": [...], "field_name": value})` |
| 暂停等待 | 暂停 Agent，等待用户输入后继续 | 调用 `interrupt(...)` |

## 9. Card（展示卡片）

### 后端对应

```python
# 类型定义: agentickit/prosonaagent/aom/types.py -> AOMCard
# 构建辅助: agentickit/prosonaagent/aom/card.py -> build_content_card / build_record_card / build_report_card
# 触发方式: LLM 调用 _builtin_send_user_content(action, params)
#          → EnhanceTaskMiddleware.awrap_tool_call 拦截
#          → 调用 handler.aget_card(state, action, params)
#          → 返回 AOMCard
```

### AOMCard 结构（与代码严格一致）

```python
class AOMCard(TypedDict, total=False):
    id: str                                           # 必填. 卡片标识
    name: str                                         # 必填. 卡片显示名称
    type: Literal["content", "record", "report"]      # 必填. 卡片类型
    data: dict | AOMCardRecordData | AOMCardReportData # 必填. 卡片数据
    description: str                                  # 可选. 给 LLM 看的文本描述
    ext: Dict[str, Any]                               # 可选. 业务扩展字段
```

### 三种卡片类型

| type 值 | 用途 | data 结构 | 构建函数 |
|---------|------|----------|---------|
| `"content"` | 展示业务内容（最常用） | 自定义 dict | `build_content_card(id, name, content, description)` |
| `"record"` | 学习记录 | `{sco_id: str, order: int}` | `build_record_card(id, name, sco_id, sco_order, description)` |
| `"report"` | 报告 | `{artifact_id: str}` | `build_report_card(id, name, artifact_id, description)` |

### 设计格式

```
卡片ID（id）:       ___（如 "quiz-display"）
卡片名称（name）:    ___（如 "展示解析"）
卡片类型（type）:    content | record | report
触发 action:        ___（LLM 调用 _builtin_send_user_content 时传的 action 值）
触发时机:           ___（什么场景下 LLM 会调用这个 action）

data 字段（给前端渲染）:
  - 字段名: 类型     # 说明
  - 字段名: 类型     # 说明

description（给 LLM 的描述）:
  "___"              （LLM 看到这段文字后决定怎么接话）
  或使用 Langfuse 模板: 模板key + 变量列表

ext（可选，业务扩展）:
  - 字段名: 类型     # 说明
```

### description 的作用

`description` 是卡片展示后塞给 LLM 的反馈文本。LLM 看到这段文字后知道"用户现在看到了什么"，据此决定接下来说什么。

格式: `"user can see the content: {description}"` （框架自动拼接前缀）

## 附录 B: 关键约定汇总

### 命名约定

| 对象 | 格式 | 示例 |
|------|------|------|
| task_group_name | 小写英文，单词 | `"project"`, `"activity"`, `"sco"` |
| handler name | `{group}:{type}` | `"sco:quiz"`, `"sco:lecture_summary"` |
| tool 函数名 | 小写下划线 | `move_to_next_item`, `search_poi` |
| card id | 小写中划线 | `"quiz-display"`, `"route-card"` |
| Langfuse key | 路径式 | `"v2/plugin/sco/quiz/content"` |
| State 类名 | PascalCase + TaskState | `QuizTaskState`, `ProjectTaskState` |
| Schema 类名 | PascalCase + Schema | `ActivityExtendSchema` |

### 返回值约定

所有生命周期方法（abefore / aafter / ...）返回 **增量 Dict**：

- 框架负责 merge 到 state
- `messages` 字段是追加模式（不会覆盖已有消息）
- 其他字段是覆盖模式
- 返回 `None` 表示不修改任何状态

### result 字段约定

`end_task` 时传入的 `result: Dict[str, Any]`，常见字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `summary` | str | 任务完成摘要 |
| `reason` | str | 结束/中断原因 |
| `next_intent` | str | 用户的下一步意图 |
| 其他自定义 | Any | 业务自定义字段 |
